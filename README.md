# bf-to-mips-compiler
A rust-based compiler that turns Brainf**k code into MIPS assembly code. This is a simple laboratory exercise under UP DIliman's CS 155: Compiler Design.

To load the compiler, place <filename>.bf file in the root folder then run it with cargo. To run the assembly code, load it with [MARS MIPS](https://dpetersanderson.github.io/).
